# Micelle–Dasiglucagon LLPS

Code, reduced data, analysis scripts, and representative simulation inputs supporting the manuscript:

**“Charge Density Effect of Micelles on Liquid–Liquid Phase Separation”**

**Mohsen Farshad, Atanu Baksi, and Jonathan K. Whitmer**

## Overview

This repository contains the computational analysis workflow and reduced data supporting our study of liquid–liquid phase separation (LLPS) in mixtures of charged micelles and dasiglucagon (DG).

The study examines how micelle charge affects phase behavior, DG organization, binding, and dynamics.

The original large molecular-dynamics trajectory files are not included because of their size. The reduced numerical data required to reproduce the quantitative manuscript figures are included in this repository.

## Repository contents

- `analysis/` — original analysis scripts used during preparation of the manuscript
- `plotting/` — portable scripts used to reproduce the manuscript figures
- `reduced_data/` — reduced numerical data used by the plotting scripts
- `inputs/` — representative LAMMPS simulation input files
- `tools/` — scripts used to prepare selected reduced datasets
- `run_all_plots.sh` — reproduces the quantitative manuscript figures
- `requirements.txt` — required Python packages

## Reproducing the manuscript figures

Install the required Python packages:

```bash
pip install -r requirements.txt
```

Then run:

```bash
./run_all_plots.sh
```

The generated figures are written to:

```text
reproduced_figures/
```

The script reproduces the computational plots corresponding to:

- Figure 3 — charge and zeta-potential mapping
- Figure 5 — phase behavior
- Figure 6b — DG density profiles
- Figure 7 — bound and unbound DG populations
- Figure 8 — radial distribution functions
- Figure 9 — DG mean-square displacement and mobility

These plots are generated using only code and reduced data contained in this repository.

Figures containing schematics, molecular representations, or simulation snapshots are not generated by `run_all_plots.sh`.

## Original analysis and reduced data

The `analysis/` directory contains the original scripts used to process the simulation data during preparation of the manuscript.

The `plotting/` directory contains portable versions that use only the reduced data included in this repository.

The reduced datasets include quantities such as replica-averaged phase behavior, DG density profiles, radial distribution functions, binding populations, mean-square displacement data, and mobility-related quantities.
