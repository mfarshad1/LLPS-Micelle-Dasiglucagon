# LLPS Paper – Data and Analysis

This repository contains example simulation inputs, reduced data, and analysis scripts supporting the results reported in the associated manuscript.

## Repository structure

- `inputs/` – Representative simulation input files
- `reduced_data/` – Processed data used to generate manuscript figures
- `analysis/` – Analysis and plotting scripts
- `figures/` – Reproduced figures or figure-generation information

Full simulation trajectories and additional data are available from the corresponding author upon reasonable request.
